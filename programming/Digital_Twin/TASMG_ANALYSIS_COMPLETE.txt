ROOT CAUSE ANALYSIS
═══════════════════════════════════════════════════════════════════════════════

BUG LOCATION: src/simulation/physics_engine.py

WHAT WAS WRONG:
  The code maintained a FIXED 60-second averaging window for historical gravity
  data. When motors stopped, the gravity vector instantly became [0, -9.81, 0],
  but the history still contained 30-60 seconds of OLD ROTATIONAL data where
  Gx ≠ 0 and Gz ≠ 0.
  
  Result: Time-averaged gravity = mixture of old rotation + new 1g
         This decayed SLOWLY over 60 seconds instead of jumping to 1g

MATHEMATICAL PROOF:
  When stopped:
    Current gravity = [0, -9.81, 0]  ✓ Correct instantly
    But history from t-30 to t contains:
      - First 30 sec: Rotating data = [0.3, -9.81, 0.2], [0.2, -9.81, 0.4], ...
      - Last 30 sec: Stopped data = [0, -9.81, 0], [0, -9.81, 0], ...
    
    Average = ([0.3×30+0×30]/60, -9.81, [0.2×30+0×30]/60)
            = [0.15, -9.81, 0.10]  ← NOT [0, -9.81, 0]!
    
    Magnitude = √(0.15² + 9.81² + 0.10²) ≈ 9.81  ← Correct
    But as time passes, old data ages out:
      t+1s: Average = [0.145, -9.81, 0.097]
      t+5s: Average = [0.10, -9.81, 0.067]
      ...
      t+60s: Average = [0, -9.81, 0]  ← Finally!

USER SEES: taSMG slowly decreases from 0.98 to 1.00 over 60 seconds ✗


THE FIX (NOW IMPLEMENTED)
═══════════════════════════════════════════════════════════════════════════════

STRATEGY: Adaptive History Management

KEY INSIGHT:
  When motors STOP, the physics state changes INSTANTLY. The averaging window
  should reflect this instant change, not delay it.

IMPLEMENTATION (3 State Machine):

  STATE 1: Motors RUNNING (ω > 0.01 rad/s)
  ─────────────────────────────────────
  Action: Keep full 60-second history
  Why:    Need to average many rotation angles to show microgravity quality
  Result: Smooth, low-noise taSMG value
  Effect: No change from original behavior ✓
  
  
  STATE 2: Motors STOP TRANSITION (ω → 0, detected)
  ────────────────────────────────────────────────
  Action: CLEAR all old history
  Why:    Physics state changed, dump old rotational data
  Fresh:  Start with current gravity = [0, -9.81, 0]
  Result: taSMG JUMPS to 1.0g immediately ✓ ← FIXES THE BUG!
  
  
  STATE 3: Motors STOPPED (ω ≈ 0, steady)
  ──────────────────────────────────────
  Action: Keep only 5-second window
  Why:    Brief window shows system is stable at 1g
  Result: taSMG stays at 1.0g (not slowly decaying)
  Effect: Intuitive - stopped motors = 1g ✓
