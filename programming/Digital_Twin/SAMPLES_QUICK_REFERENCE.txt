QUICK REFERENCE: "SAMPLES" METRIC
==================================

WHAT IS IT?
───────────
A counter that shows: How many gravity measurements have been collected

WHERE IS IT?
─────────────
Dashboard → Bottom right → Yellow metric box labeled "Samples"

HOW DOES IT WORK?
──────────────────

Physics Engine
     ↓
Every 0.02 seconds (50 Hz)
     ↓
Measure gravity vector
     ↓
Add to history
     ↓
Samples counter +1
     ↓
Send to dashboard
     ↓
Display updates


HOW FAST DOES IT INCREASE?
──────────────────────────

Rate: 50 samples per second (constant)

Timeline:
  After 1 second   → 50 samples
  After 10 seconds → 500 samples
  After 1 minute   → 3,000 samples
  After 10 minutes → 30,000 samples

Growth: Linear and predictable


TIME CONVERSION:
────────────────

Samples ↔ Time
  Time (seconds) = Samples × 0.02
  Samples = Time × 50

Examples:
  1,000 samples = 20 seconds
  5,000 samples = 100 seconds  
  3,000 samples = 60 seconds (1 minute)


WHY DOES IT MATTER?
───────────────────

Reason 1: Data Quality
  - 0-100 samples   → Too noisy, don't trust taSMG
  - 100-500 samples → Early convergence
  - 500+ samples    → Reliable taSMG ✓
  - 3,000+ samples  → Excellent statistics

Reason 2: Time Reference
  - Tells you how long simulation has run
  - Without checking wall clock

Reason 3: Convergence Progress
  - Watch samples increase = simulation progressing
  - If samples stop = simulation stopped


WHAT DOES IT AFFECT?
──────────────────────

taSMG (Time-Averaged Gravity):
  More samples = More accurate average
  taSMG = average gravity over ALL samples collected

Min/Max G*:
  Updated AFTER 50 samples (wait for stability)
  Tracks minimum and maximum taSMG value


HOW TO READ THE SAMPLES VALUE?
────────────────────────────────

Dashboard shows: "Samples: 2,500"

Interpretation:
  ✓ 2,500 gravity measurements collected
  ✓ Elapsed time = 2,500 × 0.02 = 50 seconds
  ✓ taSMG is fairly reliable now (>500 samples)
  ✓ Good point to evaluate motor performance


WHEN DOES IT RESET?
────────────────────

Samples resets to 0 when:
  - Click "Reset Simulation" button
  - Stop and restart simulation
  - Reload browser page

Samples continues (doesn't reset) when:
  - Adjusting motor speeds
  - Changing frame dimensions
  - Toggling display options
  (Only stops incrementing when motors stop)


MAXIMUM VALUE?
────────────────

Samples can go very high:
  After 1 hour → ~180,000 samples
  After 24 hours → ~4,320,000 samples

However:
  History window capped at ~6,000 samples (100 seconds)
  Older samples removed (but counter keeps going)
  You'll see ~6,000 in history, but samples counter much higher


HOW TO USE THIS INFORMATION?
──────────────────────────────

Scenario 1: Just started simulation
  Samples = 10
  Action: Wait more
  Advice: taSMG still settling

Scenario 2: Early run
  Samples = 200
  Action: Test adjustments
  Advice: Trends visible but not final

Scenario 3: Good data
  Samples = 2,000
  Action: Evaluate results
  Advice: taSMG is now representative ✓

Scenario 4: Excellent data  
  Samples = 10,000+
  Action: Use for publication
  Advice: Very confident statistics


RELATIONSHIP TO OTHER METRICS
───────────────────────────────

Samples ← → Elapsed Time
  Direct relationship (50 samples/sec)

Samples ← → taSMG (Time-Averaged Gravity)
  More samples = taSMG converges better
  N→∞: taSMG → true average

Samples ← → Min/Max G*
  Updated after 50 samples
  Tracks across all samples collected


FREQUENTLY ASKED QUESTIONS
───────────────────────────

Q: Why does it always increase at the same rate?
A: Physics engine runs at fixed 50 Hz (0.02s per step)

Q: Can I control the sample rate?
A: No, it's fixed at 50 Hz for stability

Q: What happens when it reaches 6,000?
A: Oldest samples drop out, newest stay in
   Counter keeps going (shows total collected)

Q: Should I wait for high samples?
A: Yes! Wait at least 500-1000 for reliable taSMG
   Wait 3,000+ (60 seconds) for best data

Q: Do samples affect performance?
A: No, collection is automatic and efficient
   Memory managed automatically

Q: Can I pause the samples?
A: Not directly. Stop simulation to pause samples
   Or run simulation at lower motor speeds


TECHNICAL SPECIFICATION
────────────────────────

Collection Method:
  Type: Running counter
  Rate: 50 Hz (0.02 second intervals)
  Variable: n_samples = len(gravity_history)
  Location: Backend physics engine

Data Storage:
  Structure: List of gravity vectors [Gx, Gy, Gz]
  Capacity: ~6,000 entries (rolling window)
  Memory: ~1 KB per 100 samples

Transmission:
  Method: JSON via WebSocket
  Field: "samples": integer
  Update Rate: 20 Hz (dashboard refresh)


CODE REFERENCE
──────────────

Backend (src/webapp/server.py):
  n_samples = len(self.gravity_history)
  samples=int(result["n_samples"])

Frontend (src/webapp/static/index.html):
  document.getElementById('samples').textContent = data.samples.toLocaleString()
