================================================================================
                               THE PROBLEM
================================================================================

YOUR OBSERVATIONS (100% CORRECT):

1. When rotation is ZERO (φ=0, ψ=0):
   - Expected: taSMG = 1.0g, Gx = 0, Gz = 0, Gy = -9.81
   - Observed: Values not showing correctly
   
2. When motors STOP:
   - Expected: taSMG jumps to 1.0g immediately
   - Observed: taSMG shows 1 only after VERY LONG TIME
   - Observed: taSMG continues to DECREASE even post-stop
   - Your comment: "Values should increase immediately - common sense!"

ROOT CAUSE:
  The code kept a FIXED 60-second averaging window, even after motors stopped.
  When rotation stops, old rotational gravity data (Gx≠0, Gz≠0) stays in the
  average for up to 60 seconds before aging out, causing slow decay instead
  of immediate jump to 1g.

PHYSICS PRINCIPLE:
  Gravity depends ONLY on instantaneous rotation angles:
    g(t) = R(θ(t)) · [0, -9.81, 0]
  
  NOT on history:
    g(t) ≠ average of g(t-60 to t)
  
  Time-averaging is for MEASURING microgravity quality, not for COMPUTING
  the current gravity vector.

================================================================================
                              THE SOLUTION
================================================================================

IMPLEMENTED IN: src/simulation/physics_engine.py

APPROACH: Adaptive History Management

When Motors RUNNING (ω > 0.01 rad/s):
  Keep full 60-second history
  Result: Smooth, low-noise taSMG showing microgravity quality
  
When Motors STOP (ω → 0, transition detected):
  CLEAR all old history
  Start fresh with current gravity = [0, -9.81, 0]
  Result: taSMG JUMPS to 1.0g immediately ✓
  
When Motors STOPPED (ω ≈ 0, steady):
  Keep only 5-second window
  Result: Shows steady 1.0g (not decaying from old data)

================================================================================
                        PHYSICS EXPLANATION
================================================================================

When rotation angle = 0:
  ─────────────────────
  Gravity vector in sample frame:
    g_sample = R(0°) · [0, -9.81, 0]
    g_sample = I · [0, -9.81, 0]
    g_sample = [0, -9.81, 0]
  
  Therefore:
    Gx = 0 ✓
    Gy = -9.81 (pointing down)
    Gz = 0 ✓
    taSMG = magnitude = 9.81 ≈ 1.0g ✓

When rotation stops (ω → 0):
  ──────────────────────────
  The rotation angle becomes constant
  The angular velocity becomes zero
  Therefore gravity vector becomes constant
  Therefore taSMG becomes constant at 1.0g
  
  This happens INSTANTLY, not after 60 seconds
  Because physics operates in the present, not the past

Time-averaging during running:
  ───────────────────────────
  When rotating, we average many different rotation angles
  This average is LOWER than 1g (the point of microgravity!)
  We use 60 seconds to get a stable average
  
But when stopped:
  ────────────────
  We only have one angle (constant)
  Average is just that one value = 1.0g
  No need for 60 seconds of history
  5 seconds is plenty to verify stability
