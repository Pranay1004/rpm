================================================================================
                         QUICK REFERENCE GUIDE
================================================================================

MOST IMPORTANT FORMULAS:
════════════════════════

1. Gravity Vector (Equation 2 - Paper):
   Gx = -sin(φ)·cos(ψ)
   Gy = -cos(φ)
   Gz = sin(φ)·sin(ψ)

2. Time-Averaged Simulated Microgravity (THE KEY METRIC):
   G* = √(⟨Gx⟩² + ⟨Gy⟩² + ⟨Gz⟩²)
   
   Target: < 0.003g (excellent microgravity)

3. Convergence Model:
   G*(t) = 0.003 + 0.497·e^(-t/1200)   [for t in seconds]
   
   Time constant τ ≈ 20-30 minutes

MOST IMPORTANT METRICS:
═══════════════════════

1. Instant |g| = √(Gx² + Gy² + Gz²) = 1.0 (always)
2. Average Gravity = ⟨Gx⟩, ⟨Gy⟩, ⟨Gz⟩ (should be ~0)
3. taSMG = G* (main metric - minimize this!)
4. Samples = how many data points collected
5. Elapsed Time = simulation runtime

================================================================================
                       METRIC INTERPRETATION GUIDE
================================================================================

WHEN RUNNING SIMULATION:
════════════════════════

After 1 minute:
  ✓ Simulation is initializing
  ✓ G* will be 0.1-0.5g (not yet converged)
  ✓ Sphere trajectory is sparse

After 10 minutes:
  ✓ System has stabilized
  ✓ G* should be 0.01-0.05g (converging)
  ✓ Sphere trajectory becoming more uniform

After 30 minutes:
  ✓ Excellent microgravity achieved
  ✓ G* should be 0.003-0.01g (very good)
  ✓ Sphere trajectory appears uniform

After 60 minutes:
  ✓ Near-perfect convergence
  ✓ G* approaching 0.003g (theoretical limit)
  ✓ Sphere fully covered


PROBLEM DIAGNOSIS:
══════════════════

If G* is NOT decreasing:
  → Check motor speeds (must be > 0.5 RPM)
  → Check γ ratio (should be near 1.0)
  → Verify simulation is actually running

If one component (Gy) stays constant:
  → Check if only one motor is running
  → Verify motor speed ratio is good

If sphere trajectory clusters:
  → Motor speeds may have repeating pattern
  → γ ratio might be too simple (e.g., exactly 1.0)
  → Try γ = 2.0/2.1 (irrational ratio)

If computer is slow:
  → Reduce broadcast rate (increase WebSocket interval)
  → Reduce chart history size
  → Use WebGL renderer (already default)
